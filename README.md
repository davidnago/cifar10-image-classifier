# CIFAR-10 Image Classifier

## Project Description

This project implements and deploys a deep-learning image classifier
using the CIFAR-10 dataset.

## Research Question

How does increasing CNN architectural complexity and applying data
augmentation affect multi-class image classification performance on
the CIFAR-10 dataset?

## Models

1. Baseline CNN
2. Deeper CNN
3. Deeper CNN + Data Augmentation

## Dataset

CIFAR-10 contains ten image classes.

## Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Streamlit
- scikit-learn
- Matplotlib

## Deployment

The trained model is deployed using Streamlit.

## Limitations

The model was trained on CIFAR-10 images and may not generalise
reliably to arbitrary real-world photographs outside the training
distribution.
